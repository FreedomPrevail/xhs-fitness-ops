# Content Orchestrator Contract

Orchestrator owns order/state, not domain judgment.

Sequence:
`Topic Agent -> Golden Retriever -> Content Agent -> Content Reviewer -> Outline Agent -> Visual Director -> Cover Directions -> Image Planner/ImageGen -> local infographic renderer -> Carousel Reviewer -> Canva package`.

It must preserve every agent's structured output, knowledge-unit links and evidence IDs. It does not bypass either Reviewer and never publishes automatically.
